Airplane Crash Analysis Dashboard

An interactive dashboard analyzing airplane crashes worldwide — built using **Power BI** with insights derived from crash data between 1908 and 2009.  
This project showcases my skills in **data analysis**, **visual storytelling**, and **dashboard creation**.

---

## 📊 Project Overview

This project aims to:
- Analyze trends and patterns in airplane crashes.
- Identify top causes and affected regions.
- Provide interactive filtering by year, location, and aircraft type.

It uses real-world data and visualizes key insights in an easy-to-understand dashboard.

---

## 🚀 Features

- 📈 **Interactive Power BI Dashboard**
- 📅 Year-wise crash analysis
- 🌍 Location-wise filtering
- ✈️ Aircraft type breakdown
- 📋 Total crashes, fatalities, and survival rates
- 🗂️ Downloadable reports (PDF and PBIX)
